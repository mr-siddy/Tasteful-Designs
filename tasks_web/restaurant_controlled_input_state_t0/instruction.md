Guests request a table by writing to us through the form near the middle of the
site — their name, an email, which evening they want, how many are coming, where
they would like to sit and a note for the kitchen.

Right now the form will not take anything down. You click into the name box and
type, and the letters never appear: the box stays empty no matter how long you
hold a key. The same is true of the email box, the evening box and the note to
the kitchen, and picking a different party size or a different table from the two
dropdowns snaps straight back to the four guests and the long table it started
on. The little summary above the button never stops reading "holding 4 seats at
the long table" for a name nobody has written, the character count under the note
stays at zero, and when the request is finally sent the confirmation greets an
empty name and promises to write back to an empty address. Two people have called
us this week to ask whether the website is broken, and it is.

Typing should show what was typed, straight away, in every one of those fields.
The choices in the two dropdowns should stick where the guest puts them, the
summary above the button should keep pace with what has been filled in, and the
confirmation after sending should read the guest's own details back to them.

Everything else about the page — the wording, the menu, the layout, the fields we
ask for and the order they come in — should stay exactly as it is.
