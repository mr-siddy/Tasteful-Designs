Our site is one very long page — classes, the floor, the method, membership,
member results and the questions all sit one under the other — so the row of
destinations in the sticky header is the only thing telling a visitor where they
have got to. It isn't telling them anything. However far down the page you
scroll, every one of those six links looks exactly the same as it did at the
top: nothing lights up as you pass into a section, nothing changes when you
carry on into the next one, and scrolling back up doesn't change it either. Two
members at the desk this week said they gave up and used the browser's find
because they couldn't tell whether they were still reading about classes or had
already gone past membership.

What we want is the ordinary thing every long page does: as you scroll, the
header link for the section you are currently reading is marked as the one you
are in — visibly different from the other five, and only ever one of them at a
time. It should keep up going down the page, going back up, and when someone
jumps straight to the bottom. Someone using a screen reader should get the same
information the sighted visitor gets, so the current destination needs to
announce itself as the current one rather than looking identical to the rest.

Nothing else about the page should change: the same six destinations in the same
order with the same labels, all the sections still there with the same copy,
and the rest of the site untouched.
