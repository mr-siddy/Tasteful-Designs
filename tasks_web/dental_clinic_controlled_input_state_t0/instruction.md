Marta on the front desk says the appointment request form on our landing page has
stopped taking anything down. A visitor clicks into "Full name", types, and the box
stays empty — the letters appear for an instant and then vanish, as if something is
wiping the field after every keystroke. It is the same for the email and phone boxes
and the note at the bottom, and neither of the two dropdowns will hold the option you
pick: they snap straight back to "Not sure yet" and "Any time you have free".

Everything downstream of the fields is stuck with them. The line under the form is
supposed to change to "Thanks <name> — we will reply the same working day" as soon as
someone types their name, and it never does. The character count under the note sits at
"0 of 300" no matter how much is written. And if you send the request anyway, the
confirmation that comes back reads out a single stray letter where the name should be
and no treatment at all, so the enquiries reaching the desk are useless.

Someone filling this in should see exactly what they typed, in the field they typed it
in, with each box keeping its own answer. The line underneath should greet them by name
once they have given one, the counter should track the note as it grows, and sending the
request should confirm back the details they actually entered before the form clears
itself ready for the next visitor.

Nothing else about the page should change — the same fields in the same order, the same
treatments and times in the dropdowns, the same wording, and the rest of the site left
exactly as it is.
