Near the bottom of our studio page there is a "Questions we get asked every week"
block — seven front-desk questions you click to read the answer to. It is meant
to work the way these things normally do: you open one, you read it, and when you
open the next one the previous answer folds itself back up.

That is not what it does. Every question you click stays open. Click the one about
contracts, then the one about a bad back, then parking, and now there are three
answers sitting on the page at once and the questions underneath have been pushed
most of a screen further down. Someone working through the list ends up with all
seven expanded and a wall of text with no way to tidy it up except clicking each
one shut again. The little plus icons agree with the mess — several of them show
as open at the same time.

Opening a question should show that one answer and close whichever answer was
already open, so there is never more than one on screen. Clicking the question
that is currently open should still close it and leave nothing expanded, and the
block should still load with every answer collapsed the way it does now.

Don't change the questions or the answers themselves — same seven, same wording,
same order — and leave the rest of the page alone.
