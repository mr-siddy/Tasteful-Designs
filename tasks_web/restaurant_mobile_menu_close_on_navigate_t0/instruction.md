Guests keep telling us the site is unusable on a phone, and it turns out they
are all describing the same thing. On a narrow screen the header collapses down
to the little stack-of-lines button, and tapping it slides open the list of
destinations — Menus, The Fire, Sourcing, Private Events, Visit, and the reserve
button underneath. That part is fine. What is not fine is what happens when you
actually choose one: the list just sits there, full width, covering everything
underneath it. The page has gone where you asked, but you cannot see any of it
until you notice the little close button up in the corner and press it yourself.
Two people this week thought the site had frozen.

Choosing a destination from that list should take you to it and get the list out
of the way at the same time — the same goes for the reserve button inside it.
After that the header should be back to normal, so tapping the button again
brings the list up as it did before, and a screen reader should hear that it is
closed rather than still open. Opening and closing it from the header button
alone should keep working exactly as it does today.

Nothing else about the page changes: the same destinations in the same order,
the same wording, the same desktop header, and every section below it untouched.
